# Kyle’s Guinea Pig Club

A responsive guinea pig website with real photos, food and care categories, rotating facts, and a name generator.

Open `public/index.html` in a browser, or run:

```sh
python3 -m http.server 8000 --directory public
```

Then visit http://localhost:8000. No build or dependencies required. Fonts use Google Fonts with local fallbacks. Photos are stored locally in `public/images/`; photographer credits and source links are on the page. Care information links to RSPCA guides.

## Pages

- `public/index.html`: photos, care categories, facts, and name generator.
- `public/species.html`: species and origins.
- `public/breeds.html`: American, Abyssinian, and Peruvian breeds.
- `public/videos.html`: Smithsonian guinea pig video (internet required), with a direct YouTube fallback.
- `public/styles.css`: shared responsive styling.
